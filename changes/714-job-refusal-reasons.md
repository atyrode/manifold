A refused job door now answers with the check that refused it instead of one constant sentence for every cause, so reading a finished job's output or journal says whether the capability, the grant, the consent row, the retained node or the caller's own plugin pin stopped it — and a withdrawn consent is distinguishable from one that was never granted. Diagnosing a refusal no longer takes one experiment per candidate check.
