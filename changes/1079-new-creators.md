section: Changed
issue: 1079
---

The sidebar's three creation rows are now one control that reads as a phrase: "+ New Canvas ▾". Pressing "+ New" makes another of the current choice in one press; the choice beside it opens a keyboard-accessible menu listing what you can create by name (Canvas, Composition, Folder), in order, with the current one marked. Choosing an entry makes it and keeps it as the choice, remembered on this device. On the collapsed rail the control is a single "+" that opens the menu. New folder now creates "Untitled folder" in one press and opens it for renaming in the Index. The existing New canvas, New composition and New folder settings keep their values and now show or hide that menu entry, and a disabled plugin's entries disappear. Sidebar sections other than Index now start folded on a device that has never opened them, and whichever sections you fold or unfold stay that way after a reload. Any plugin, including a hardened one, can add an entry by declaring `contributes.creators` in its manifest: the name of the thing it makes, a mark from a closed icon set, an order, the action to run with a fixed input, and an optional own setting; a sidebar section can declare `defaultOpen` to start unfolded. Plugin manifests carrying either field require protocol 58, and `core.index.createFolder` now also answers the created `folderId`.
