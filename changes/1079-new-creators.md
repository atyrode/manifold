The sidebar's three creation rows are now one quiet "+ New…" row. Pressing it turns the row into a draft entry: type the name, pick what to create from the titles listed under the field (Canvas, Composition, Folder) or step through them with Tab, and press Enter. The thing is made already named, or with its default name when the field is empty; Escape cancels, and clicking away cancels an empty draft and makes a named one. A refused creation keeps the draft and what you typed. The draft opens on whatever you last created on this device. On the collapsed rail the control is a single "+" that opens the rail with the draft. The existing New canvas, New composition and New folder settings keep their values and now show or hide that entry, and a disabled plugin's entries disappear. Sidebar sections other than Index now start folded on a device that has never opened them, and whichever sections you fold or unfold stay that way after a reload. Any plugin, including a hardened one, can add an entry by declaring `contributes.creators` in its manifest: the name of the thing it makes, a mark from a closed icon set, an order, the action to run with a fixed input, the input property that carries the typed name (`nameInput`), and an optional own setting; a sidebar section can declare `defaultOpen` to start unfolded. Plugin manifests carrying either field require protocol 58, and `core.index.createFolder` now also answers the created `folderId`.
