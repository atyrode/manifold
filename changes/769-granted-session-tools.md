Operators can explicitly grant digest-pinned plugin action tools and narrow that selection for each Run. A matching native harness can bind a plain job to the Run and use the existing worker channel for policy acknowledgement and bounded tool results without putting a general Run bearer in the workload. Calls retain current scope, contributor and lifecycle checks; cancellation and unknown acknowledgements remain distinct from successful effects. Ordinary jobs and empty tool selections acquire no new authority. Hardened harnesses now expose their declared interface with asynchronous guest-side profile validation and live authority checks; this requires repacking for contract 7.
