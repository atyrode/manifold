Agent rows in Sessions now open a compact run inspector, also available headlessly through `core.access.inspectAgentRun`. Root, the run itself and its actual sponsors see only their authorized run chain: purpose, scope, policy, credential and connection life, action attempts and trace references, native lifecycle links and cleanup, with pruned origins and unsettled work shown honestly. Selected delegation and native-execution actions require a bounded, redacted agent declaration; it is a claim, never permission or proof. Credentials, private arguments, environment, terminal bytes and retained output stay out of the inspector.
