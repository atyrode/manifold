---
section: Breaking Changes
issue: 402
---

Plugin discovery is now a public allowlist: anonymous protocol discovery, the plugin list for any signed-in credential and the session plugin frame name each installed plugin's pin and packing mode but no longer its installation source, installer, install time, granted capabilities, toggle attribution or build and update diagnostics. Those receipts move to a private read that requires the new `plugins:read` capability, plugin-engine events withhold who acted from readers without it, and a plugin's own server half still reads its own receipt. Loading installed plugin code and stylesheets now requires `plugins:load`, and reading your own workspace layout requires `layouts:read`; root keeps full access, while existing narrow credentials, shares and preview identities gain none of the new capabilities and need explicitly delegated scoped credentials. Without them the plugin manager says which receipts are private, a refused plugin is named as not loaded, and a workspace whose saved layout could not be read shows a default arrangement without ever saving it over the unread one. Session, machine and instance sockets now close an unknown first frame before admission, while unknown frames after admission are still ignored. This coordinated protocol 59 cutover requires a current SDK. The released OMP, Code and Babel bundles (stamps 47 and 48) keep loading; bundles stamped 51 to 56 are held until repacked.
