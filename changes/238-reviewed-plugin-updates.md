Installed third-party plugins can declare a release feed, show available updates, and review a whole plugin family before applying it. The review names exact versions and pins, capability changes and retained grants, dependencies, executable halves, data migrations, compatibility and changelogs; increased capability ceilings need explicit consent. Failed precommit updates restore the family's managed data and prior bundles. Known protocol or React-major incompatibilities are held before code runs and can be repaired with a compatible update. Core plugins still update with Manifold, and unpacked plugins with their source tree. The browser protocol is now 45.
