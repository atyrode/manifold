Numbered previews include the configured portable development environment, with zsh, OMP, Code and development tools available in their existing terminals. Preview deployments verify the pinned environment before stopping the running preview, preserve ordinary canvas and identity data, and run the application as an unprivileged developer user. Redeployment replaces the disposable development home and retires existing terminal processes and their terminal entries.
