Add opt-in Files with private immutable storage, bounded authenticated uploads and reads, explicit named sharing, and separate logical deletion. Publication and transfer receipts preserve exact retry identity without restoring revoked access, and retained file bytes survive server restart independently of the uploader's connection. Files includes an authenticated library, canvas images and explicit managed-machine delivery. Terminal drops offer Save and Deliver separately; only a verified destination path can be copied or deliberately inserted without Enter. Native MIME paste remains non-retained. Native admission refusals retire their exact queued reservation even before a transfer ID is returned. Failed delivery cleanup releases its private receiving descriptor before journaling on a full destination filesystem, so reclaimed space can durably record the failure without inventing a successful copy. Concurrent Files requests wait within their original deadline instead of colliding with a private publication or native-evidence callback. Only callback-owning isolates exclude unrelated requests; private callbacks re-enter through the current host-owned call, and idle maintenance still declines a busy owner without borrowing action authority. Signed plugin code bundles support up to 64 MiB so native decoder dependencies and upstream notices remain inside the bounded artifact. File uploads, image limits, private storage quotas and the updater's separate family budget are unchanged.
Private API metadata is explicitly non-cacheable, slow byte requests return their bounded timeout before the HTTP connection expires, and expired unpublished preparations release capacity without reclaiming committed files. Full-state recovery preserves exact migration-journaled database images and validates them without creating sidecars; compiled and source-free recovery helpers retain the same protocol.
