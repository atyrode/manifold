---
section: Breaking Changes
issue: 156
---

Plugins can declare pinned machine artifacts, native terminal runtimes and bounded worker operations under explicit installation, resource and invocation consent. Readiness reflects the proved owner and each operation's current tools, anchors and scoped services, not terminal connectivity. The plugin manager exposes exact resource bindings and caller-to-callee approvals; mounted container authoring places governed terminals in canvases and compositions. Native service configuration uses compare-and-set promotion; projected read operations need scoped service authority rather than an arbitrary execution grant, and each upstream request is reauthorized and attributed before I/O. Action delegates retain the original caller's grants, scope and revocation. Source credentials remain behind native references, while runtime services use acknowledged, workload-owned private listeners and parent-bound native jobs. Linux jobs require held filesystem mounts, cgroup containment and seccomp; unavailable backends refuse execution rather than falling back to ambient programs. Private writable homes admit explicit sealed configuration, and terminal ownership and output sealing require positive workload-empty proof. Maintenance also waits for pending direct service mutations. Input requests use fresh correlated IDs and owner-confirmed cursors; asynchronous receipts distinguish accepted input from unknown delivery without replay. Protocol 30 requires an upgraded hub and transport; native owner RPC is independently versioned at 29. Terminal-host IPC 2 declares governed versus unconfined admission, and missing declarations never authorize ambient shell creation. Upgrade target hubs before transports, retain compatible owners, and safely quiesce owners before replacing their binaries; source publication authorizes neither hub promotion nor fleet installation.
Scoped runtime HTTP requests use an ownership-proved established connection, with no
reconnect to a cached port. Another workload taking over a released listening port
cannot receive the runtime's subsequent scoped request data or bearer.
Linux service providers receive an explicit unsupported-optimization error for deferred
TCP accept, preserving accepted-peer ownership before any request or bearer bytes.
Owner-declared credential references can remain in integrity-protected root-managed
directories; the credential files themselves remain private and owner-held. Plugin
development can prepare generated worker bundles through the native development loop,
without introducing a second watcher or installer.
Protected credential paths require traversal, not directory-listing access; pinned
directory identities preserve exclusion checks and durable state commits. Native
owner shutdown releases the runtime-owned listener socket exactly once.
Machine-only bundles are complete plugins when their pinned artifacts and operations
validate; they need no inert web or server entry point.
Native revalidation preserves root authority for ordinary browser tokens as well
as the owner key. Service-configuration delegates retain their explicit capability
ceiling; non-owner, insufficiently delegated and revoked credentials remain refused.
Restored owners publish cached installation resources while admission remains drained.
Transport loss does not cancel retained work merely because unrelated authority is
reconciled; current grants, consent and pinned policy remain enforced.
Native NixOS startup enables delegated controllers from the owner's main subgroup,
not an `ExecStartPre` process that prevents systemd from starting its executor.
The disposable module check covers authenticated native readiness and retained
machine identity and owner PID across hub and transport restarts.
Native NixOS execution can consume an explicitly declared enrollment credential through
systemd `LoadCredential` while its original tool retains custody. Unsafe ownership,
permissions, ACL write masks and path indirection refuse transport startup; no token
copy, rotation or owner restart is performed. The packaged VM check covers private
read-only delivery, custody refusals and retained work across transport replacement.
