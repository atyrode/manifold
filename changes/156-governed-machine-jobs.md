---
section: Breaking Changes
issue: 156
---

Plugins can declare verified machine artifacts and run bounded, non-PTY operations under explicit installation-revision/hash-bound resource consent, with durable job identity, cancellation, private output, authority attribution and shared scheduling. Readiness reflects the current proved job owner, not terminal connectivity. Linux x64/arm64 jobs require held filesystem mounts, cgroup containment and seccomp; unavailable backends refuse jobs without disabling terminal transport. Create-only locations refuse existing targets, and named outputs require already-provisioned bounded tmpfs capacity within the shared output budget. Sealing waits for overlapping authorized writers, not unrelated jobs. Host networking is separately explicit and remains subject to descriptor-export syscall restrictions. Protocol 26 adds governed job traffic only for protocol-26 agents while retaining previously compatible terminal agents and their terminal-program guards; the additive machine extension requires no fleet restart. Instance peers require protocol 26 because their closed capability/reference vocabularies expanded, and ordinary session clients remain exact-version. Upgrade target hubs before installing newer-protocol agents; publishing this release authorizes neither hub promotion nor fleet installation.
