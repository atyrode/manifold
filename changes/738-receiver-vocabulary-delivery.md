The retained-process receiver can explain a refusal in the environment it exists for. Its vocabulary was a data file read at runtime, and that file was never added to the installed-tooling list the preview verification copies, so every lookup missed where it mattered: a real refusal on the integrated preview — `fingerprint-unreadable-denied`, the probe being denied a process fingerprint — was reported as "a predicate this receiver does not know", which is the collapse the vocabulary was written to end, arriving one layer further out. Both receivers now carry the sentences themselves, so a meaning cannot fail to be delivered, and the test that already compared the two receivers word for word is what keeps them from drifting.
