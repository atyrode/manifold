External agents can use the SDK-backed `manifold-action-runner` to discover live action schemas, create an accountable run, explicitly acknowledge exact server policy, invoke actions, delegate bounded children, renew and re-acknowledge policy, and finish without browser control. The runner keeps sponsor and child credentials inside its process and returns bounded mechanical outcomes with the existing durable trace id; session and plugin tooling now share the same HTTP action transport. Interruption, malformed input and EOF attempt run teardown and distinguish confirmed cleanup from expiry-backed uncertainty.
