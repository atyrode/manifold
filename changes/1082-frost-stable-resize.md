In the landing concept's frost scene, resizing the window no longer swaps the pane for a different, fully grown frost pattern: the same fronds stay where they grew, each half of the pane following its own edge, and only a few branches down the middle change. Dragging the window edge no longer stutters, since the pane regrows once the new shape has rested, and untouched glass now costs next to nothing each frame. Every pattern looks different once with this fix.
