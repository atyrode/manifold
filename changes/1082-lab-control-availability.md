In the landing concept lab's Controls view, a setting the "changed" lens counts is now always on screen. If the switch it depends on is off, the setting appears dimmed next to that switch, and you can reset it there. A search no longer shows a group whose only match is folded away. A setting that depends on a switch which itself depends on another switch now hides when either switch is off, instead of showing for a feature that is off. The instance name now counts as a change, and the Page group's reset clears it. Each changed control's reset dot is now fully visible. Tab no longer stops on controls inside folded groups. On touch screens, a vertical swipe that starts on the direction pad, the birds strip, a mix divider or a readout now scrolls the panel instead of changing a value. Switches, sliders, help buttons and reset dots have larger touch targets, and help buttons and fader amounts are visible without hovering. A sync that changes nothing no longer rewrites the panel.
