An optional `atyrode.github` plugin can be packed and explicitly installed to publish operator-reviewed issues through preprovisioned owner-native GitHub services. Its public doors return the exact marked title and body before review, preserve current requester and service authority, and durably fence duplicate or uncertain creates across restart. Explicit fixed-repository reconciliation can recover a real issue receipt without another POST. The provider is not installed by default and does not enroll credentials, borrow CLI authentication, publish private evidence, or require Babel or Code.
