An optional `atyrode.github` plugin can be packed and explicitly installed to publish operator-reviewed issues through preprovisioned owner-native GitHub services. Its public doors return the exact marked title and body before review, preserve current requester and service authority, and durably fence duplicate or uncertain creates across restart. Explicit fixed-repository reconciliation can recover a real issue receipt without another POST. The provider is not installed by default and does not enroll credentials, borrow CLI authentication, publish private evidence, or require Babel or Code. CI dependency analysis retains JSON-backed exports as data-module provenance, so authored manifest imports no longer obscure authorization risk or affected test discovery. Native Bun vendor pins include the additional workspace on all four supported platforms; the existing independent rebuild and compiled-package smoke gates remain required.
