A retained-process probe that admitted after a denied read says how many were refused, instead of admitting silently. Admitting is what the probe now does with a fingerprint read the kernel refused on a process it then proves had exited, and an admission that recorded nothing left that handling invisible: a run where the condition arose and was handled read exactly like a run where it never arose, so whether the environment exercises the path at all could only be argued from fixtures. What changes is how often a disclosure appears, not what it discloses — the same bounded integer a refusal already carried, with no pid, name, path or argument — and the line stays absent at zero so it carries information whenever it appears.
