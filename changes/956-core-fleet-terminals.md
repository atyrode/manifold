NixOS can explicitly provision an existing OS account for ordinary core terminals independently of governed execution, preserving its home, shell, groups, profile commands and retained owner while refusing unsafe credential custody. Linux, Darwin and NixOS onboarding leads with ordinary-account shells, without custom harness or Agent-profile prerequisites. The core Machines plugin adds atomic, revisioned host-view metadata without changing account execution or grant identities, and inventory news covers offline withdrawal, forgetting and committed maintenance latches even when owner acknowledgement refuses. Plugin action storage and database effects recheck the original live credential and admitted binding after awaited work. Live connection authority and privacy-preserving subscription-ordering fences keep scoped fleet readers fresh through fallback polling while synchronized eligible views remain event-driven, including portable Workers. Grouped hosts require explicit exact-account choice and explain unavailable shells without substitution; grouping failure preserves flat inventory. Core enrollment hands off a newly minted credential once in a selectable immutable field with explicit custody retirement, and portable client replacement retires old replies even when authority hints are identical.
Ordinary shell creation and restart now require correlated placement rights plus `machines:shell` at the exact enrolled account. Scoped V2 credentials, Agent/Run views and human Sessions delegation preserve those resource-specific rights without widening same-principal tokens, canvas homes or retained terminal lifecycle credentials. Read-only action preparation binds the normalized destination, native demand and installed code before admission; shared live fences also protect awaited and restored effects. Released global shell policy migrates once, while container-only authority and existing terminal control retain their bounds. Strict legacy views refuse unrepresentable scoped authority rather than flattening it, and retained governed/native contracts exclude the new ordinary-only capability. The terminal CLI distinguishes explicit shell delegation from lifecycle control; doctor never probes by spawning a terminal.
Retained terminals preserve mounted viewer channels, focus, selection and output across transport replacement and accept fresh input after re-adoption. Governed birth and restart retire only acknowledged admission guards, retaining live credential, sponsor, installation, consent and native-owner checks. Trusted session restart reauthorizes fresh native demand before reservation and cleans up only its rejected private launch credential.
Ordinary births and restarts acknowledged by the exact retained owner remain valid across an in-flight drain, while continuing credential and code withdrawal still fence completion.
Private host-grouping drafts keep their original revision through temporary authority uncertainty. Conflicts require explicit reload and review of the winning values, and removed groupings require closing the stale draft rather than resurrecting metadata. Pooled observers install retained interests before readiness callbacks, preserve successor authority during synchronous reconnection, and bound every subscription fence from its original invocation, including queued time.
Retained host groupings remain visible and removable after their final enrolled account is forgotten. Every roster publication retires mutable action parser object or parsing-method, handler, preparer and ceiling replacements, including equal-shape replacements, restoration of earlier objects and temporary disappearance without an intervening query. Durable native recovery preserves all captured revision-bound consent requirements, including source-job inputs.
Preparation refuses mutable host effects through retained contexts and asynchronous descendants, including parsers and target extraction for actions without a preparer. Prepared ordinary launches and restarts pin the admitted destination owner without rejecting a replacement transport for that same owner.
Harness handoffs and cold native restoration preserve the original action authority together with exact server-harness code, profile, validator, publication revision and installation bindings, without widening native credentials or retiring valid owned effects when a temporary context closes.
Fleet selection, enrollment, host grouping and finite delegation controls remain usable in a 168px sidebar in both native and portable rendering. Delegation uses separate local date and time fields so the full expiry stays visible.
Mounted machine readers converge to unknown when the ordinary inventory door becomes unreadable and require a fresh eligible catch-up after restoration. Disabling Machines retains its normal refusal boundary rather than gaining a privileged fallback. Finite delegation composition choices follow authorized index creation, renaming and removal events.
Terminal views first mounted while their retained owner is offline acquire the healing snapshot and fresh output on readoption without a room reconnect or remount. Successful authoritative inventory recovery also retires its keyed disabled-plugin notice instead of displaying stale failure beside live inventory.
Synchronous physical redial or nested authority publication stops retired frame fan-out before later observers can regain stale grants. Preparation fences supported store, room, placement and host mutation owners even through retained contexts, swallowed attempts and asynchronous descendants, while preserving pure reads and independent admitted work.
Ordinary Nix account credential and owner-state paths refuse symbolic links in every ancestor, not only at the final file. Linux native qualification preserves all five full runtime roles in serial bounded builds and accepts only a strict exact-source aggregate of complete role evidence.
Privileged Nix shell-directory provisioning resolves no-follow ancestors before creating new state and refuses root-owned aliases without repairing existing account custody. Host-view reads fall back after an event-read failure, and serialized authoritative refresh prevents stale mutation responses from restoring removed metadata. Composed action calls enforce caller ceilings for selected and retained prepared engine requirements.
Hardened contract-12 native preparation sends only a nonsecret runtime selector and commitment; actual terminal admission recomputes and matches the full private binding before any authority decision or native effect.
This coordinated session-protocol cutover requires a compatible current SDK; prior container-only remote launchers need explicit shell re-delegation, while existing terminal control remains available.
