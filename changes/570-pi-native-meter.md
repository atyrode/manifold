A metered service operation can now name the wire it actually speaks. Beside `openai-usage`, a proxy operation may declare `meter: { kind: "pi-native-usage" }` for pi-ai's own gateway wire, where a request names its model as `modelId` beside a `context.messages` array and a turn states its tokens as `usage.input`, `usage.output` and `usage.cacheRead` on the terminal frame — the frame that wire always sends, so the owner amends nothing on the way out and the bytes reach the caller exactly as before. The fresh and cached input buckets are added back into one input total with the cached part named inside it, priced by the same policy `prices` map keyed on the model the request named, so a job that drives omp through omp's own gateway is metered like any other: one `inference_call` in the journal per call with the model, the tokens and the cost, and `usage.inference` on the settled record. A stream that ends without its usage frame did not complete a turn, and is recorded as the refusal the caller was answered with rather than as a call that happened to cost nothing. The native owner protocol moves with this release, so a machine still on the previous one is fenced from execution until its agent is upgraded; drain it first.
