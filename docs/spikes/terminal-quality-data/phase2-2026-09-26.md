# Terminal quality phase-2 data (2026-09-26)

Raw records for experiments 6–9 of the [terminal quality investigation](../terminal-quality-investigation.md#phase-2-non-native-measurements-2026-09-26). Everything here is synthetic fixture output from disposable loopback instances at source revision `a7fed226259f9e76a81342046f1ffaa5319a1d3b`; no production session, credential or personal terminal content is included. Environment and endpoint definitions are in the investigation's conditions table.

## Reproducing

The measurement harness was throwaway and is not committed. It can be rebuilt from these parts:

- **Instances.** Experiment 6 uses `packages/testkit` `startServer`, `enrollMachine`, `startAgent`, `createContainer` and `mintToken` (one human grant with `containers:read`, `scenes:write`, `terminals:spawn`, `terminals:write`), and opens the fixture with `SessionClient.openTerminal({ placement: "tile", program: { argv: [bun, fixture] } })`. Experiments 7–9 spawn `packages/server/src/main.ts` with `MANIFOLD_SPAWN_AGENT=1` and a web bundle built from the same checkout, create one human principal through `core.access.createPrincipal`, open the fixture beside a plain shell with `openTerminal` plus `core.space.place` (split composition), and log Chromium in by seeding that grant into `localStorage["manifold.identity"]`, exactly as `scripts/bench-terminal-ui.ts` does.
- **Browsers.** `scripts/cdp.ts` `Browser.launch({ incognito: true })`, CDP `Emulation.setDeviceMetricsOverride` for viewport/DPR, real `Input.dispatchMouseEvent`/`Input.dispatchKeyEvent` for clicks, divider drags (24 moves, 25 ms apart, sinusoidal ±18% of the pane, released 12% off the start) and keystrokes. Slow devices use `Emulation.setCPUThrottlingRate` (4 or 20) or `Debugger.pause`/`Debugger.resume`.
- **In-page probe** (installed with `Page.addScriptToEvaluateOnNewDocument`; measurement only). It walks React fiber `memoizedProps.terminalId` from each `.xterm-host` to the TerminalView hook whose ref holds the live xterm `Terminal`; wraps that instance's `write(data, cb)` to record bytes written/parsed and the arrival and write-callback time of every `@@[TKJP]:<n>:<epoch ms>@@` marker; wraps `resize(cols, rows)` to classify each size change as applied inside a write callback (ordered with the stream) or elsewhere (and, in the ablation, to skip the latter); subclasses `WebSocket` to count received frames, `terminal_snapshot` frames and `channel_closed` frames. Grid fit is compared with the host box from `getBoundingClientRect` of `.xterm-host` and `.xterm-screen`.
- **Viewer emulation (experiment 6).** Each SDK viewer's decoded stream is replayed into `@xterm/headless` 6.0.0 (scrollback 2,000) with `write(bytes up to the event)` then `resize(cols, rows)` at every `resized` event's stream offset; the late attacher's snapshot is written into a fresh terminal at the final grid; the serialization control loads `@xterm/addon-serialize` on the emulated live terminal and replays `serialize({ scrollback: 5000 })`.

Commands are line-oriented on the fixture's stdin (sent with `SessionClient.sendTerminalInput`). Block copies count buffer lines matching `/\[BLK:0:F\d+:/`.

### Fixture: resize ordering (experiment 6)

Commands: `stream <ms>`, `inline`, `anim <ms>`, `stop <n>`, `draw <n>`, `clear <n>`.

```text
import { writeSync } from "node:fs";
const wall = () => performance.timeOrigin + performance.now();
const emit = (text) => { const b = Buffer.from(text); let o = 0; while (o < b.length) o += writeSync(1, b, o, b.length - o); };
const size = () => {
  const r = Bun.spawnSync(["stty", "size"], { stdin: "inherit", stdout: "pipe", stderr: "pipe" });
  const [rows, cols] = r.stdout.toString().trim().split(/\s+/).map(Number);
  return { rows, cols };
};
let g = size(), line = 0, winch = 0, mode = "idle", frame = 0, prevLines = 0, timer = null;
const H = 6;
const block = () => {
  frame += 1;
  const w = Math.max(10, g.cols - 1);
  let out = "";
  for (let i = 0; i < H; i++) {
    const label = "[BLK:" + i + ":F" + frame + ":" + g.cols + "x" + g.rows + "]";
    out += (label + "=".repeat(w)).slice(0, w) + (i < H - 1 ? "\r\n" : "");
  }
  return out;
};
const inline = () => {
  // Relative erase using the line count the program itself wrote (it wraps its own text
  // to its current width and does not know how the terminal reflowed earlier rows).
  let erase = "";
  if (prevLines > 0) erase = "\r" + (prevLines > 1 ? "\x1b[" + (prevLines - 1) + "A" : "") + "\x1b[J";
  emit(erase + block());
  prevLines = H;
};
process.stdin.setRawMode(true);
if (Bun.spawnSync(["stty", "-echo", "-opost"], { stdin: "inherit" }).exitCode !== 0) process.exit(7);
process.on("SIGWINCH", () => {
  g = size(); winch += 1;
  if (mode === "stream") emit("@@W:" + winch + ":" + g.cols + "x" + g.rows + ":" + wall().toFixed(3) + "@@\r\n");
  else if (mode === "inline") inline();
});
const tick = () => {
  line += 1;
  const head = "@@L:" + line + ":" + g.cols + "x" + g.rows + "@@";
  emit((head + ".".repeat(g.cols)).slice(0, g.cols - 1) + "\r\n");
};
let pending = "";
process.stdin.on("data", (chunk) => {
  pending += chunk.toString("utf8");
  for (;;) {
    const end = pending.indexOf("\n");
    if (end < 0) break;
    const [cmd, arg] = pending.slice(0, end).split(" ");
    pending = pending.slice(end + 1);
    if (cmd === "stream") { mode = "stream"; clearInterval(timer); timer = setInterval(tick, Number(arg)); }
    else if (cmd === "inline" || cmd === "anim") { mode = "inline"; clearInterval(timer); timer = null; prevLines = 0; emit("\x1b[2J\x1b[3J\x1b[H"); inline(); if (cmd === "anim") timer = setInterval(inline, Number(arg)); }
    else if (cmd === "stop") { clearInterval(timer); timer = null; mode = "idle"; emit("\r\n@@STOP:" + arg + "@@\r\n"); }
    else if (cmd === "draw") { g = size(); emit("\r\n@@D:" + arg + ":" + g.cols + "x" + g.rows + "@@\r\n"); }
    else if (cmd === "clear") { emit("\x1b[2J\x1b[3J\x1b[H@@CLR:" + arg + "@@\r\n"); }
    else if (cmd === "quit") process.exit(0);
  }
});
setTimeout(() => process.exit(6), 900_000);
```

### Fixture: paced producer (experiments 8–9)

Commands: `flow <id> <bytes/s, 0 = unpaced> <marker ms> <duration ms>`, `ping <id>`, `clear <id>`; Ctrl+K (0x0b) and Ctrl+] (0x1d) are echoed as `@@K:` and `@@J:` markers with per-device counters reset by `clear`.

```text
import { writeSync } from "node:fs";
const wall = () => performance.timeOrigin + performance.now();
const emit = (text) => { const b = Buffer.from(text); let o = 0; while (o < b.length) o += writeSync(1, b, o, b.length - o); };
let marker = 0, keys = 0, keysJ = 0, running = null;
const colors = [31, 32, 33, 34, 35, 36];
const filler = (n) => {
  let out = "";
  let i = 0;
  while (out.length < n) {
    const c = colors[i++ % colors.length];
    out += "\x1b[" + c + "m" + "build step " + String(i).padStart(6, "0") + " " + "ok ".repeat(20) + "\x1b[0m\r\n";
  }
  return out;
};
const block = filler(262144);
async function flow(id, bytesPerSec, markerMs, durationMs) {
  const start = wall();
  let sent = 0, nextMarker = start, offset = 0;
  emit("@@BEGIN:" + id + ":" + wall().toFixed(3) + "@@\r\n");
  while (wall() - start < durationMs) {
    const t = wall();
    if (t >= nextMarker) { marker += 1; emit("@@T:" + marker + ":" + wall().toFixed(3) + "@@\r\n"); nextMarker += markerMs; }
    const due = bytesPerSec === 0 ? 65536 : Math.min(65536, (t - start) / 1000 * bytesPerSec - sent);
    if (due > 0) {
      const n = Math.floor(due);
      let chunk = block.slice(offset, offset + n);
      if (chunk.length < n) chunk += block.slice(0, n - chunk.length);
      offset = (offset + n) % block.length;
      emit(chunk);
      sent += n;
    }
    await new Promise((r) => setTimeout(r, bytesPerSec === 0 ? 0 : 2));
  }
  emit("\x1b[0m\r\n@@END:" + id + ":" + wall().toFixed(3) + ":" + sent + "@@\r\n");
}
process.stdin.setRawMode(true);
if (Bun.spawnSync(["stty", "-echo", "-opost"], { stdin: "inherit" }).exitCode !== 0) process.exit(7);
let pending = "";
process.stdin.on("data", (chunk) => {
  let text = chunk.toString("latin1");
  if (text.includes("\x0b") || text.includes("\x1d")) {
    for (const ch of text) {
      if (ch === "\x0b") { keys += 1; emit("@@K:" + keys + ":" + wall().toFixed(3) + "@@\r\n"); }
      if (ch === "\x1d") { keysJ += 1; emit("@@J:" + keysJ + ":" + wall().toFixed(3) + "@@\r\n"); }
    }
    text = text.replaceAll("\x0b", "").replaceAll("\x1d", "");
  }
  pending += text;
  for (;;) {
    const end = pending.indexOf("\n");
    if (end < 0) break;
    const [cmd, id, a, b, c] = pending.slice(0, end).split(" ");
    pending = pending.slice(end + 1);
    if (cmd === "flow") { running = flow(id, Number(a), Number(b), Number(c)); }
    else if (cmd === "ping") emit("@@P:" + id + ":" + wall().toFixed(3) + "@@\r\n");
    else if (cmd === "clear") { keys = 0; keysJ = 0; emit("\x1b[2J\x1b[3J\x1b[H@@CLR:" + id + "@@\r\n"); }
    else if (cmd === "quit") process.exit(0);
  }
});
setTimeout(() => process.exit(6), 1_800_000);
```
